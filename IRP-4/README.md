# IRP-4 midterm report

**A recommender system to re-orient investments towards more sustainable technologies and businesses**

- **Doctoral candidate** · Mohamed Faid
- **Affiliation** · University of Twente

Paper catalogue snapshot dated 24 November 2026. [MSCA research profile](https://msca-dn-digital-finance.github.io/irps/irp-4.html)

## Research interests

The project designs a recommender system to direct investment toward more sustainable firms and technologies. It examines how to measure sustainability and tailor the explanations behind recommendations to different users.

**Candidate interests** · Machine Learning, System Design, Mathematics.
